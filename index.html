HOW TO PLAY

A / ◀ Left : Move Left
D / ▶ Right : Move Right
W / Space / ▲ : Jump (hold higher)
Shift / J : Run / Sprint faster
P / Escape : Pause Game
M : Toggle Sound & Music
• Question Blocks (?): Jump underneath to pop coins and secrets.
• Enemies: Stomp walking mushrooms and turtles from above! Bouncing off gives upward lift.
• Turtle Shells: Stomp a turtle once to make it retract, then run into it or kick it to send it sliding into enemies!
• Checkpoints: Touch the mid-level green post to set a respawn point.

🎮 Desktop: A/D or Arrows to Move | Space/W to Jump | Shift to Sprint | P to Pause

📱 Mobile: Use on-screen virtual buttons | 🔊 Pure 8-Bit Web Audio Engine
